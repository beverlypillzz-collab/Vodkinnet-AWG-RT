# bcrypt.__about__.__version__, which bcrypt removed in 4.1.0. With
# bcrypt>=4.1 this doesn't break hashing/verification (passlib traps
# the AttributeError internally) but it logs a scary-looking
# "(trapped) error reading bcrypt version" on every startup. Pinning
# avoids the noise entirely rather than teaching operators to ignore
# what looks like an error.
